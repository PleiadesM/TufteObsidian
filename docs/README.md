# Tufte for Obsidian — the documentation page

`index.html` is the theme's documentation site, served by GitHub Pages from this `docs/` folder: the theme in its own Reading-view style, English and 中文, light and dark, with the install and set-up guide, every style in action, and the change log.

It is a single self-contained file (fonts, images and pre-rendered math inlined) generated from the theme's development vault — `TufteCSSDev/.web-export/build.py` — never edited by hand here. To change the page, edit the sources in the vault and rebuild; the build writes this copy.
